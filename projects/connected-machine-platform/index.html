Industrial Edge & Connected Machines

01

Executive Summary

The work joined product discovery, field constraints, software architecture, industrial protocols, edge execution, and live-machine validation.

I led five engineers and two interns developing OPC UA gateways, data collectors, MQTT tooling, programmable I/O modules, and edge-automation components. My role was not management at a distance: I personally defined machine-state models and interfaces, implemented software components, worked with technicians in plants, and built an embedded-adjacent control system spanning browser UI, Python compilation, and C execution.

12live machines
3production plants
7engineers + interns led

02

Field Pilots + Machine Data

Plant visits with technicians, production leaders, and operators established the real constraints. Retrofitting had to capture useful machine states without requiring each installer to become a networking or automation specialist.

01

Connect physical machines

Retrofitted approximately 12 live machines with physical I/O connectivity and digital twins.

02

Model usable state

Mapped machine states, faults, cycle times, and utilization into a consistent data model.

03

Move data safely

Connected edge and factory flows through OPC UA, MQTT, HTTPS, Azure SQL, and partner interfaces.

04

Serve operations

Supplied data to MES and production-scheduling systems while partner teams retained their application logic.

Installation UX

I translated plant feedback into guided, step-by-step setup concepts that hid unnecessary TCP/IP and automation complexity from electricians, with advanced controls kept in administration workflows.

03

Edge Product Portfolio

The product portfolio covered the software layer around physical systems: data acquisition, communication, local behavior, guided setup, and interfaces to higher-level factory applications.

Gateway

OPC UA at the edge

Integrated an OPC Foundation SDK into an embedded gateway and worked with FreeRTOS-based execution.

Connectivity

Published MQTT library

Developed the CODESYS MQTT client library in alignment with IEC 61131 and released it through the CODESYS Store.

Data

Machine to enterprise

Built data collectors and interfaces spanning physical I/O, edge protocols, cloud data, MES, and scheduling.

04

Hands-On Build: Distributed Local Control

One representative prototype moved simple control behavior from a central PLC into intelligent field I/O. I built a browser-based function-block programming application, a Python compiler that generated stack-machine instructions, and an embedded C interpreter that executed the resulting logic on the target.

05

Outcome + Evidence Boundary

The pilots proved that the connected-machine concepts could work with real factory equipment, field constraints, and production-system interfaces.
