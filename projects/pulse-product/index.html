01

Executive Summary

I took PULSE from the first concept to a live game with a persistent football world, responsive management workflows, mobile app surfaces, real time updates, and daily production operation.

I owned the full path from game and schema decisions through frontend and backend implementation, testing, release, monitoring, defect investigation, data recovery, and user support. The production system processed approximately 28,000 application events triggered by users each day.

02

Game and Pixel Level UX

The game covered scheduling, leagues, cups, tactics, player development, reports, transfers, and support tooling. I designed the responsive behavior and iterated individual screens using game instrumentation, funnel analysis, A/B tests, community feedback, and direct observation of user friction.

Measured game decision

Deferring registration until after initial play, replacing the tutorial with milestone guidance, and tuning game pace increased the number of new users completing their first lineup by 236%.

03

Systems + Production Operations

I designed the application database, schemas, backend logic, Node.js REST APIs, admin tooling, and real time workflows backed by PocketBase. I also owned Docker delivery, Linux operations, DigitalOcean, AWS S3, monitoring, releases, investigation, and recovery.
