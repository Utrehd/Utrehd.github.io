How I work

Define the constraint, model the system, and validate the result.

I work across product discovery, domain modelling, implementation, release, and support. The objective is a workflow that users can understand and operators can verify.

  1. 01
    Define the operating problem

    Start with users, operators, and available evidence. Separate the visible symptom from the constraint that creates it.

  2. 02
    Model decisions and state

    Make the data, workflow, failure paths, and ownership explicit before simplifying them in the interface.

  3. 03
    Release with evidence

    Test the behavior, document the decision, observe the outcome, and connect production feedback to the next change.
